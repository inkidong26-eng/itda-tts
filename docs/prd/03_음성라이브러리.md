# 03. 음성 라이브러리

## 1. 목표
- 행사판: 7개 나이대 × 남녀 × **1~2개 = 14~28개**. 1차로 14개를 확실히 완성하고, 시간이 되면 28개.
- 출시판: 70개 이상.
- 모든 음성은 **6가지 감정 + 떨림**을 낼 수 있어야 한다.

## 2. 엔진: Qwen3-TTS (Apache-2.0)
| 모델 | 하는 일 | 감정 지시 |
|---|---|---|
| VoiceDesign 1.7B | 글 설명으로 새 목소리 만들기 | 가능 |
| CustomVoice 1.7B / 0.6B | 내장 화자 + 말투 지시 | 가능 (단, 내장 화자만) |
| Base 1.7B / 0.6B | 약 3초 음성으로 목소리 복제 | **불가** |

> 공식 저장소 기준 정보이며, 한국어 품질과 감정 표현 정도는 **T03 검증 작업에서 직접 확인 후 확정**한다.

## 3. 제작 방식 (T03 결과로 A/B/C 중 하나 선택)

**방식 A — 설계 후 복제 (1순위 후보)**
1. VoiceDesign으로 음성마다 설명문 + 감정별 기준 문장을 생성 → 감정별 기준 음성 파일(각 5~8초) 7개 확보 (평온·기쁨·슬픔·화남·놀람·간절·떨림).
2. 실제 서비스에서는 Base 모델이 "해당 감정의 기준 음성"을 복제해 말함 → **같은 목소리 + 감정 유지**.
3. 장점: 음색이 일정함. 단점: 기준 음성 품질에 전적으로 의존.

**방식 B — 매번 설계**
- 요청마다 VoiceDesign에 "목소리 설명 + 감정 지시"를 함께 넣음.
- 장점: 감정 표현이 풍부. 단점: 문장마다 음색이 조금씩 달라질 수 있음.

**방식 C — 혼합**
- 평온·기쁨은 A, 떨림·간절처럼 미묘한 감정은 B.

**결정 기준 (T03):** 같은 음성으로 10문장을 만들어 들었을 때 "같은 사람"으로 들리는가(사용자 직접 판정), 감정 6종이 구분되는가, 1문장(20자) 생성 시간.

## 5. 기준 문장 (감정별, 모든 음성 공통)
| 감정 | 기준 문장 | 감정 지시(설계 시 추가) |
|---|---|---|
| 평온 | 안녕하세요, 오늘 만나서 반갑습니다. 천천히 이야기 나눠요. | 차분하고 편안하게 |
| 기쁨 | 와, 정말요? 너무 기뻐요! 오늘 최고의 하루예요. | 밝고 신나게, 웃음기 있게 |
| 슬픔 | 그 이야기를 들으니 마음이 많이 아파요. 정말 속상해요. | 낮고 느리게, 슬프게 |
| 화남 | 이건 정말 아니라고 생각해요. 다시 확인해 주세요. | 단호하고 힘 있게, 약간 화난 |
| 놀람 | 어? 정말이에요? 전혀 몰랐어요! | 놀라서 높고 빠르게 |
| 간절 | 제발 한 번만 도와주세요. 정말 부탁드려요. | 간절하고 애원하듯 |
| 떨림 | 저… 사실은… 조금 무섭고 걱정돼요. | 목소리가 떨리고 말끝이 흔들리게, 머뭇거리며 |

## 6. 제작·검수 절차 (T05, T06)
1. 스크립트 `services/tts/scripts/build_voices.py` 가 `voices.yaml`(이 표)을 읽어 음성별 기준 음성 7개를 생성 → `assets/voices/{id}/{emotion}.wav`.
2. 같은 스크립트가 미리보기용 문장("안녕하세요, 저는 ○○이에요. 만나서 반가워요.") 음성 + **파형 이미지(PNG)** 생성.
3. **사람 검수:** 간단한 검수 웹페이지(`/admin/voices`)에서 음성마다 7개를 듣고 ✅/🔁(다시 생성)/❌ 표시. 🔁는 시드(seed)를 바꿔 다시 생성.
4. 검수 통과 음성만 `voices.json` 에 `"approved": true` 로 등록되어 앱에 노출.
5. 검수 기준: 나이·성별이 맞게 들리는가 / 발음 오류 없음 / 감정 구분됨 / 잡음·끊김 없음.

## 7. 외래어·숫자 읽기 (한국어 정규화)
TTS에 보내기 전 텍스트를 한국어 읽기로 바꾼다 (`services/api/app/text_normalize.py`).
- 사전 방식: `OK→오케이`, `Thank you→땡큐`, `WiFi/와이파이`, `카톡`, `ㅇㅋ→오케이`, `ㄱㅅ→감사`, `ㅈㅅ→죄송` 등 (초기 100개 이상, 목표 200개, 파일로 관리해 추가 쉽게).
- 숫자: `3시→세 시`, `010-1234-5678→공일공 일이삼사 오육칠팔`, `5,000원→오천 원`, `2026년→이천이십육 년`.
- 이모지·ㅋㅋ·ㅠㅠ는 **읽지 않고** 감정 단서로만 사용 (04 참조). 단, "ㅋㅋㅋ"만 단독으로 보내면 가벼운 웃음 소리 문장 "하하"로 바꿔 읽음.
- 영어 문장이 통째로 들어오면 한국어 발음 표기로 변환 시도, 실패 시 그대로 전달 (Qwen은 영어도 읽을 수 있으나 목소리 톤이 달라질 수 있음).

## 8. 미리 만들어 두는 음성 (캐시) — 행사 부하 대비 핵심
- 즐겨찾기 기본 12문구 × 승인된 음성 × (평온 + 문구에 맞는 감정 1개) 를 **행사 전에 미리 생성**해 정적 파일로 배포.
- 기본 12문구: 안녕하세요 / 감사합니다 / 죄송합니다 / 잠시만 기다려 주세요 / 다시 한번 말씀해 주시겠어요? / 천천히 말씀해 주세요 / 네, 알겠습니다 / 아니요, 괜찮습니다 / 얼마예요? / 화장실이 어디예요? / 도와주세요 / 만나서 반가워요
- 사용자가 같은 문장 + 같은 음성 + 같은 감정을 다시 보내면 서버 캐시에서 즉시 재생.
