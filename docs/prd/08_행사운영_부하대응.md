# 08. 행사 운영 · 500명 부하 대응 · 비용

## 1. 부하 추정 (가정 — 리허설 측정으로 갱신)
- 참가자 500명 중 **같은 시간대에 실제로 쓰는 사람 최대 250명** 가정 (세션 체험 시간).
- 1명이 평균 20초에 한 문장 → 초당 약 **12~13건** 음성 요청 (최고치).
- 즐겨찾기 문구·같은 문장 반복으로 **30% 이상은 캐시**에서 즉시 처리 → GPU가 처리할 요청 초당 약 9건.
- GPU 1대가 초당 처리할 수 있는 문장 수(동시 처리 포함)는 **T03·T22에서 실측**한다.
- 필요 GPU 수 = 초당 9건 ÷ (GPU 1대 처리량) × 1.5(여유). 예) 1대가 초당 3건이면 → 약 5대.

> 이 숫자는 가정입니다. 11/5 부하 테스트 1차, 11/9 2차 결과로 확정합니다.

## 2. 부하를 줄이는 장치 (모두 행사판 필수)
1. **즐겨찾기 미리 생성** (03 문서 8절) — 체험 첫 문장의 상당수가 "안녕하세요".
2. **같은 문장 캐시** — 사람마다 비슷한 문장을 친다.
3. **글자 수 100자 제한** — 화면에서 안내.
4. **대기열 + 비상 전환** — 2.5초 안에 시작 못 하면 폰 기본 음성으로 즉시. **무음은 절대 없다.**
5. **입장 안내 분산** — QR 안내를 세션별로 나눠 한꺼번에 몰리지 않게 (진행자와 협의).
6. **GPU 미리 깨우기** — 행사 당일은 모든 GPU를 행사 1시간 전부터 켜 두고 `warmup` 확인.

## 3. 비용 (대략, 실제 견적은 T21에서)
| 항목 | 평소 (월) | 행사 당일 |
|---|---|---|
| 웹앱 정적 호스팅 | 무료 플랜 | 무료 플랜 (트래픽 충분) |
| API 서버 (소형 VPS) | 약 1만원 안팎 | 하루만 사양 올리기 가능 |
| GPU | 개발·시연 때만 켜기 → 약 3~4만원 한도 안에서 사용 | 24GB급 GPU 여러 대 × 약 8시간 (시간 단위 과금) |
| 감정 AI (선택) | 사용 시 소액 | 사용 시 소액 |
| **합계** | **5만원 이하 목표** | **별도 견적 (부하 테스트 후 확정)** |

- GPU는 **반드시 사용 후 끈다.** 켜 두면 예산이 바로 넘는다. → T21에서 "켜기/끄기 스크립트"와 "잊지 않게 알림" 마련.
- 업체·요금은 자주 바뀌므로 행사 1주 전(11/5) 기준 견적을 다시 확인.

## 4. 리허설 (11/10) 체크리스트
- [ ] 실제 폰 20대 이상 (안드로이드 10대·아이폰 10대, 오래된 기종 포함)
- [ ] 행사장 와이파이 + 휴대폰 데이터 양쪽에서 접속
- [ ] QR 접속 → 가입 → 첫 음성 60초 이내
- [ ] 대면 모드: 상하 분할, 자막, 감정 칩, 단어 하이라이트, 진동/테두리 빛
- [ ] 링크 통화: 짝 10쌍 동시, 재생 확인 신호, 끊김 후 재연결
- [ ] 스피커폰 방식: 안드로이드·아이폰 각 2대 (통신사 다르게)
- [ ] GPU 1대를 일부러 끄기 → 다른 GPU로 넘어가는지 / 모두 끄기 → 기본 음성으로 넘어가는지
- [ ] 부하 도구로 초당 15건 10분 유지 → 응답 시간 기록
- [ ] 농인 당사자 테스터의 의견 (가능하면 2명 이상)
- [ ] 무음 모드 폰에서 "폰 소리를 켜 주세요" 경고가 뜨는지
