# 05. 시각·촉각 피드백 — "지금 내 글이 소리로 나가고 있다"를 눈과 손으로

## 원칙
- 농인은 소리를 확인할 수 없다. **음성이 실제로 재생되는 동안에만** 표시가 움직여야 한다 (가짜 애니메이션 금지).
- 모든 표시는 실제 재생 중인 오디오를 Web Audio `AnalyserNode` 로 분석한 값에서 나온다.
- **단순하고 가볍게.** 오래된 폰에서도 초당 30프레임 이상 유지. 8밴드 이퀄라이저는 출시판 선택 기능으로 미룬다.

## 1. "말하는 중" 막대 (확정: 1개)
- 위치: 보낸 말풍선 바로 아래 + 대면 모드 위쪽(청인 쪽) 영역.
- 모양: 가로 막대 1개, 소리 크기(RMS)에 따라 길이와 밝기가 변함. 색은 메시지 감정 색.
- 재생 시작 시 "🔊 말하는 중", 끝나면 "✅ 전달 완료" 글자로 바뀜.
- 실패 시 "⚠️ 소리가 나지 않았어요 — 다시 말하기" 버튼.
- 무음 감지: 재생 중인데 0.5초 넘게 소리 크기 0 → 경고 (폰 무음 모드·음량 0 가능성 안내: "폰 소리를 켜 주세요").

## 2. 말하는 단어 하이라이트 (노래방 자막 방식)
- Qwen은 단어별 시간 정보를 주지 않으므로 **음절 수 비례로 추정**한다 (한국어는 음절 길이가 비교적 고르다).
  - 전체 재생 길이 ÷ (음절 수 + 쉼 가중치) 로 각 어절 시작 시각 계산. 문장 부호 쉼은 05-1 무음 길이만큼 더함.
  - 문장을 여러 조각으로 나눠 생성하는 경우 조각 단위로 다시 맞춤 → 오차 누적 방지.
- 표시: 이미 읽은 어절은 진한 색, 지금 읽는 어절은 감정 색 배경 + 살짝 크게, 아직 안 읽은 어절은 옅은 회색.

## 3. 감정 색·아이콘
- 04 문서 표를 따름. 말풍선 왼쪽 세로 띠 + 아이콘, 대면 모드 경계선 색.

## 4. 청인 목소리 크기 표시
- 마이크 입력 크기를 작은 원형 표시로 (말하면 원이 커짐) + "🎤 상대가 말하는 중".
- 자막이 생성 중이면 회색 글자로 먼저 보여주고, 확정되면 진한 글자로.
- 대면 모드: 농인 화면 아래쪽 / 통화 링크 모드: 청인이 말하는 소리는 서버를 거치지 않으므로, 청인 폰에서 보낸 "말하는 중" 신호로 표시.

## 5. 진동 (안드로이드)
- `navigator.vibrate()` 사용. 소리가 날 때 소리 크기에 맞춰 짧은 진동 펄스.
  - 100ms 마다 소리 크기 측정 → 기준 이상이면 `vibrate(40)` (강하면 60). 너무 잦으면 배터리·불쾌감 → 최소 간격 120ms.
- 이벤트 진동:
  | 이벤트 | 패턴 |
  |---|---|
  | 음성 시작 | 짧게 1회 (50) |
  | 전달 완료 | 짧게 2회 (40, 60, 40) |
  | 실패 | 길게 1회 (300) |
  | 통화 상대 연결됨 | 3회 (60, 80, 60, 80, 60) |
  | 상대 연결 끊김 | 길게 2회 (300, 150, 300) |
  | 청인 자막 도착 | 아주 짧게 1회 (30) |
- 설정에서 끌 수 있음.

## 6. 테두리 빛 (아이폰 + 모든 기기 공통 보조)
- 아이폰 브라우저는 웹 진동을 지원하지 않음 → **화면 가장자리 테두리 빛**으로 대체. 안드로이드에서도 켜 둘 수 있음.
- 화면 테두리 6~10px, 감정 색, 투명도가 소리 크기에 따라 0.2~1.0으로 맥동.
- 이벤트: 완료 = 2번 깜박, 실패 = 빨간색 3번 깜박, 연결 = 초록 3번 깜박.
- 광과민 배려: 초당 3회 이상 깜박이지 않음.

## 7. 구현 메모
- 오디오 재생은 하나의 `AudioContext` 와 재생 큐로 관리 (`apps/web/src/audio/player.ts`). 재생 큐 덕분에 연속으로 보낸 문장이 겹치지 않음.
- 아이폰은 첫 터치 이후에만 오디오가 열리므로 S1·S8의 첫 버튼에서 `AudioContext.resume()`.
- 폰 기본 음성(비상용 브라우저 음성 합성)은 AnalyserNode로 분석이 안 되는 경우가 많음 → 이때는 `onboundary`/`onstart`/`onend` 이벤트로 하이라이트·막대를 **단순 패턴**으로 표시하고 "기본 목소리" 배지를 함께 보여준다.
