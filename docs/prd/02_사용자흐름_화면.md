# 02. 사용자 흐름과 화면 명세

## 공통 디자인 원칙 (농인·시니어 접근성)
- **소리에 의존하는 안내 금지.** 모든 상태(전송됨, 말하는 중, 실패, 연결됨)는 글자 + 색 + 아이콘으로 표시.
- 기본 글자 18px 이상, 버튼 높이 56px 이상, 대비 4.5:1 이상. 글자 크기 3단계(보통/크게/아주 크게) 설정.
- 한 화면에 결정 하나. 문장은 짧게, 그림·아이콘 위주.
- 색: ITDA 브랜드(청록 #1A9A9A 계열 ~ 남색 #1E3A8A 계열, 포인트 주황 #F08A4B). 감정 색은 04 문서 참조.
- 세로 화면 기준, 폭 360px 폰에서 가로 스크롤 없음.

## 전체 흐름

```
[QR/링크] → S1 시작 → S2 이름 → S3 나이·성별 → S4 목소리 고르기 → S5 홈
                                                         ├─ S6 마주보고 대화 (대면 모드)
                                                         ├─ S7 전화로 대화 (통화 모드, 농인)
                                                         └─ S9 설정
청인: [농인이 보낸 링크/QR] → S8 받는 화면 (가입 없음)
```
두 번째 접속부터는 S1~S4를 건너뛰고 **S5 홈**으로 바로 들어간다 (폰에 저장된 정보 사용).

---

## S1. 시작 화면
- ITDA 로고, 슬로건 "소리가 없어도, 우리는 이어집니다."
- 버튼 1개: **[시작하기]**
- 작은 안내: "이 앱은 글을 목소리로 바꿔 상대에게 들려줍니다. 상대방은 설치가 필요 없어요."
- 하단 한 줄: "홈 화면에 추가하면 앱처럼 쓸 수 있어요" (안드로이드는 설치 버튼, 아이폰은 '공유 → 홈 화면에 추가' 그림 안내). 건너뛸 수 있음.
- **첫 터치 시 할 일:** 소리 재생 권한 활성화(브라우저는 첫 터치 이후에만 소리를 낼 수 있음), 음성 서버 미리 깨우기 요청(`/tts/warmup`).

## S2. 이름 입력 (실명)
- 입력칸 1개: "이름을 적어 주세요" (2~20자, 한글·영문)
- 체크 1개(필수): "행사 체험을 위해 이름을 저장하는 데 동의합니다. 행사 후 ○○일 이내 삭제됩니다." (기간은 10번 문서에서 확정)
- **[다음]**

## S3. 나이·성별
- 나이대: 큰 버튼 7개 — 10대 / 20대 / 30대 / 40대 / 50대 / 60대 / 70대 이상
- 성별: 큰 버튼 2개 — 남성 / 여성
- 의미 안내: "내 목소리를 추천해 드리기 위해 사용해요."

## S4. 목소리 고르기
- 선택한 나이·성별에 맞는 **추천 3개**를 카드로 보여준다. (해당 조합 음성이 1~2개뿐이면 인접 나이대에서 채움)
- **농인용 목소리 카드** — 소리를 듣지 않고도 한눈에 느낌을 알 수 있게 (내용은 청인 평가자가 실제로 듣고 작성, 03 문서 6절):
  - 목소리 이름 + 나이대·성별 (예: "🌸 봄볕 · 20대 여성")
  - **쉬운 한 줄 설명** (예: "밝고 또렷해요. 말이 조금 빨라요.") — 소리 전문용어(중저음·톤 등) 쓰지 않기
  - **👂 듣는 사람 느낌** (예: "친절한 카페 직원 같아요") — 연예인 비교 금지
  - **눈금 4줄 (점 5개):** 높이(낮음↔높음), 빠르기(느림↔빠름), 분위기(차분함↔밝음), 힘(부드러움↔힘참)
  - 어울리는 자리 (예: "친구 대화, 가게 주문"), **파형 그림**(미리 만든 이미지)
  - 글은 아주 짧고 쉬운 말로 (수어가 첫 언어인 농인 배려), 눈금 그림이 중심
- [들어보기] 버튼: 재생되는 동안 파형이 움직이고 진동/테두리 빛 → 농인도 "소리가 나는 중"임을 확인. 옆에 있는 청인에게 들어봐 달라고 할 수 있음.
- [다른 목소리 보기] → 해당 나이대 전체 목록.
- **[이 목소리로 할게요]** → 서버에 사용자 생성, 폰에 저장 → S5.
- 고른 목소리는 이후 **기본값으로 계속 사용**. 설정(S9)에서만 바꿀 수 있음.

## S5. 홈
- 인사: "○○님, 반가워요" + 현재 목소리 이름
- **큰 버튼 2개** (화면의 대부분을 차지)
  - 🧑‍🤝‍🧑 **마주보고 대화** → S6
  - 📞 **전화로 대화** → S7
- 하단: 설정(톱니), 즐겨찾기 문구 관리
- 음성 서버 상태 표시점: 초록(준비됨) / 노랑(깨우는 중, "잠시만요 — 목소리를 준비하고 있어요") / 회색(기본 음성 사용 중)

## S6. 마주보고 대화 (대면 모드) — 상하 분할

```
┌──────────────────────────┐
│  ↻ (180° 뒤집힌 영역)      │  ← 청인 쪽: 탁자 건너편에서 바로 읽힘
│  농인이 방금 보낸 문장 (큰 글씨) │
│  말하는 단어 하이라이트       │
│  "말하는 중" 막대             │
├──────────────────────────┤  ← 경계선 = 감정 색
│  청인 말 자막 (실시간)         │  ← 농인 쪽
│  🎤 청인 목소리 크기 표시      │
│  대화 기록 (말풍선, 위로 스크롤) │
│  [감정 칩 6개 + 떨림]         │
│  [즐겨찾기 ⭐] [입력칸] [보내기] │
└──────────────────────────┘
```
- 위쪽 영역: CSS 회전 180°. 농인이 보낸 마지막 문장을 아주 큰 글씨로 표시, 소리에 맞춰 단어 하이라이트.
- 아래쪽: 농인의 작업 공간.
  - 입력칸에 글을 칠 때마다 **자동 감정 추정**이 칩 위에 미리 표시됨("슬픔 · 떨림 약" 처럼). 농인이 칩을 누르면 덮어씀.
  - [보내기] 또는 키보드 엔터 → 즉시 음성 출력 (폰 스피커, 최대 음량 안내).
  - 청인 말은 마이크로 듣고 자막으로 표시 (05·07 참조). 마이크 켜짐/꺼짐 토글이 크게 보여야 함.
  - 농인이 음성 출력 중일 때는 **자기 음성이 자막으로 다시 잡히지 않도록** 마이크 인식을 잠시 멈춘다.
- 즐겨찾기 ⭐: 자주 쓰는 문구를 한 번 터치로 말하기 (기본 12개 제공 — 03 문서의 캐시 문구).
- 상단 작은 버튼: 홈으로, 글자 크기, 위쪽 영역 숨기기.

## S7. 전화로 대화 (통화 모드, 농인 화면)
- 방식 선택 큰 버튼 2개:
  1. **🔗 링크로 전화 걸기 (추천)** — 상대는 링크만 누르면 됨
  2. **📱 일반 전화 중에 쓰기 (스피커 방식)**
- **링크 방식 흐름:** [링크 만들기] → 화면에 QR + [문자로 보내기] [카카오톡 등으로 공유] (폰 기본 공유창) → "상대방을 기다리는 중…" → 상대 접속 시 "연결됐어요 ✅" + 진동/빛 → 대화 화면.
- **대화 화면:** S6의 아래쪽 영역과 같은 구성(대화 기록, 자막, 감정 칩, 입력칸). 상단에 "통화 중 03:21", 상대 연결 상태, [끊기].
- **스피커 방식:** 안내 그림 3단계 ("① 평소처럼 전화를 거세요 ② 스피커폰을 켜세요 ③ ITDA에 글을 치면 상대에게 들려요") → S6 아래쪽과 같은 대화 화면(위쪽 뒤집힌 영역 없음). 볼륨 최대 안내.

## S8. 받는 화면 (청인용, 가입 없음)
- 링크 접속 시: "○○님이 ITDA로 대화를 요청했어요. ○○님은 글로 말하고, 목소리로 들려드려요." → **[대화 시작]** (소리 재생·마이크 권한을 위한 첫 터치)
- 대화 중:
  - 농인 메시지가 오면 음성 자동 재생 + 큰 글씨 자막 + 감정 아이콘
  - **[🎤 누르고 말하기]** 큰 버튼 (누르는 동안 인식) + "말하기 자동 감지" 토글
  - 내 말이 글자로 바뀐 결과를 보여주고 상대에게 전송됨 표시
  - [끊기]
- 마이크를 허용하지 않으면 "글로 답하기" 입력칸을 대신 보여준다.

## S9. 설정
- 내 목소리 바꾸기 (S4 재사용)
- 기본 말하기 속도 (느리게/보통/빠르게), 기본 음량 안내
- 글자 크기, 진동 켜기/끄기, 테두리 빛 켜기/끄기
- 즐겨찾기 문구 편집 (추가/삭제/순서)
- 대화 기록 지우기 (폰에 저장된 것)
- 내 정보 삭제 (서버의 이름·선택 정보 삭제 요청)

## 오류·예외 화면 규칙
| 상황 | 표시 |
|---|---|
| 음성 서버 깨우는 중 | 노란 점 + "목소리를 준비하고 있어요 (최대 ○초)" — 그동안 보낸 문장은 기본 음성으로 즉시 재생 |
| Qwen 음성 실패/시간 초과 (GPU 차례 대기 2.5초·총 4초, 07 문서 5절) | 자동으로 폰 기본 음성 재생 + 작은 회색 배지 "기본 목소리로 말했어요" |
| 인터넷 끊김 | 빨간 띠 "인터넷 연결을 확인해 주세요" + 폰 기본 음성으로 대면 모드는 계속 가능 |
| 통화 상대 연결 끊김 | 진동 2회 + "상대방 연결이 끊겼어요" + [다시 연결] |
| 마이크 권한 거부 | "자막을 쓰려면 마이크를 허용해 주세요" + 그림 안내 |
