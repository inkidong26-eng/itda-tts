# 01. PRD 개요

## 1. 한 줄 정의
**ITDA(잇다)** — 농인이 글을 치면 내가 고른 목소리와 감정으로 즉시 말해 주고, 청인의 말은 자막으로 돌려주는 대면·통화 겸용 소통 앱.
슬로건: *"소리가 없어도, 우리는 이어집니다."*

## 2. 배경과 문제
- 필담은 느리고, 수어를 모르는 청인과는 대화가 끊긴다. 화면·노트를 계속 봐야 해 시선도 어긋난다.
- 기존 TTS는 목소리가 기계적이고 한두 개뿐이라 "내 목소리"라는 느낌이 없다.
- 무엇보다 **감정이 전달되지 않는다.** "괜찮아요"가 웃으며 하는 말인지, 울먹이며 하는 말인지 상대는 모른다.
- 농인은 **지금 내 글이 실제로 소리로 나가고 있는지** 확인할 방법이 없다.
- 전화 통화는 농인에게 가장 큰 벽이다.

## 3. 사용자

| 구분 | 설명 | 앱 사용 |
|---|---|---|
| 농인 (주 사용자) | 글 입력, 눈·손으로 확인 | **ITDA 앱 사용 (웹앱, QR/링크 접속, 설치 선택)** |
| 청인 (상대) | 가족, 수어통역사, 가게 직원, 공무원 등 | **설치·가입 없음.** 대면은 농인 폰으로 듣기, 통화는 받은 링크만 누름 |
| 기관·지자체 관계자 | 행사 참관, 출시·상업화 판단 | 시연 관찰 |

## 4. 목표

### 4-1. 행사 시연판 (2026-11-13) — 이번 PRD 범위
1. 행사 방문 약 1,000명 중 부스 방문 100~500명이 상담 부스에서 1:1~2:2 안내를 받으며 **각자 폰으로 QR 접속 → 1분 안에 첫 대화**. (같은 시간 최대 5:5, 약 10대)
2. 대면 모드: 글 → 감정 음성, 청인 말 → 자막, 상하 분할 마주보기 화면.
3. 통화 모드: 링크 통화(주력) + 스피커폰 방식(보조).
4. 감정: 자동 분석 + 감정 칩(6종 + 떨림 약/중/강).
5. 확인 표시: 말하는 단어 하이라이트, 감정 색·아이콘, 청인 목소리 크기, "말하는 중" 막대, 진동(안드로이드)/테두리 빛(아이폰).
6. 음성: 10대~70대 × 남녀, **세대·성별당 1~2개 (14~28개)**.

### 4-2. 출시판 (행사 이후, 기관 협의 결과에 따라)
- 음성 70개 이상, 본인인증 가입, 8밴드 이퀄라이저(선택 기능), 일반 전화망(010) 연결, 국내 클라우드 GPU 이전, 나만의 목소리 복제, 다국어 확장 검토.

## 5. 범위

| 포함 (행사판) | 제외 (출시판 이후) |
|---|---|
| 한국어 전용 (외래어는 한국어 발음) | 다른 언어 음성 |
| 이름 입력만으로 가입 | 휴대폰 본인인증·간편 로그인 |
| 웹앱(PWA), 안드로이드·아이폰 브라우저 | 앱스토어용 앱 |
| 링크 통화 + 스피커폰 방식 | 일반 전화망 직접 연결 |
| 대화 내용은 **폰에만 저장** | 서버 대화 저장·기기 간 동기화 |
| 즐겨찾기 문구 | 수어 카메라 인식 |
| "말하는 중" 막대 1개 | 8밴드 이퀄라이저 |

## 6. 성공 기준 (행사 당일 측정)

| 지표 | 목표 |
|---|---|
| QR 접속 → 첫 음성 출력 | 60초 이내 (중앙값) |
| 글 전송 → 소리 시작 | 중앙값 1.5초 이하, 95%가 3초 이하 |
| 기본 음성으로 전환된 비율 | 10% 미만 |
| 소리가 아예 나지 않은 경우 (무음) | 0건 |
| 앱 멈춤·하얀 화면 | 0건 (리허설 기준) |
| 자동 감정이 맞다고 느끼는 비율 | 참가자 간이 설문 70% 이상 |
| 기관 관계자 후속 협의 요청 | 1건 이상 |

## 7. 기술 방향 요약 (자세히는 07)
- 주소: `gyeot.ai.kr` 서브도메인 — `itda.` (앱), `api.` (백엔드), `tts.` (음성 서버)
- 화면: PWA 하나로 농인용 앱 + 청인용 "받는 화면"
- 백엔드: Python FastAPI (항상 켜진 소형 서버)
- 음성: **Qwen3-TTS** (Apache-2.0, 한국어 지원) — GPU 서버 분리, 평소엔 필요할 때만 켜고 행사 당일 증설
- 비상: 음성 서버가 늦거나 꺼지면 **폰 내장 음성(브라우저 음성 합성)으로 자동 전환** → 절대 무음이 되지 않게
- 예산: 평소 월 5만원 이하, 행사 당일 GPU 증설은 별도 견적
