# 04. 감정 엔진 — 글의 표현과 대화 흐름을 목소리에 담기

## 1. 목표
농인이 **따로 설정하지 않아도** 글의 표현(ㅠㅠ, !!, …, 이모지)과 앞뒤 대화 흐름으로 감정이 목소리에 실리고, 틀리면 **감정 칩 한 번 터치**로 고칠 수 있다.

## 2. 감정 체계 (확정)
| 코드 | 감정 | 색 | 아이콘 | 목소리 방향 |
|---|---|---|---|---|
| `calm` | 평온 | 청록 #1A9A9A | 🙂 | 기본 속도, 안정적 |
| `joy` | 기쁨 | 노랑 #F5B700 | 😄 | 밝고 약간 빠르게 |
| `sad` | 슬픔 | 파랑 #3B6FD8 | 😢 | 낮고 느리게, 쉼 길게 |
| `angry` | 화남 | 빨강 #D93A3A | 😠 | 힘 있게, 또박또박 |
| `surprise` | 놀람 | 주황 #F08A4B | 😲 | 높고 빠르게 |
| `plead` | 간절 | 보라 #8A5CD8 | 🙏 | 느리고 애원하듯 |

추가 값:
- **세기** `intensity`: 1(약)~3(강) — 기본 2
- **떨림** `tremor`: 0(없음) / 1(약) / 2(중) / 3(강)

메시지 하나의 감정 결과 형식:
```json
{ "emotion": "sad", "intensity": 2, "tremor": 1, "source": "auto|chip", "reasons": ["ㅠㅠ", "앞 대화: 슬픔"] }
```

## 3. 자동 분석 — 3단계 (빠른 것부터)

### 1단계: 표현 규칙 (폰에서 즉시, 0.01초)
`apps/web/src/emotion/rules.ts` — 입력 중 실시간으로 칩 위에 추정 표시.

| 단서 | 결과 |
|---|---|
| `ㅠ`, `ㅜ` 2개 이상, 😢😭🥲 | sad +2, tremor +1 (`ㅠㅠㅠ` 이상이면 tremor +2) |
| `ㅋㅋ`, `ㅎㅎ`, 😄😆🤣😊, `^^` | joy +2 |
| `!` 1개 | intensity +1 / `!!` 이상: intensity +2, 다른 감정 없으면 surprise 또는 joy |
| `?!`, `!?`, `헐`, `대박`, `진짜?`, 😲😮 | surprise +2 |
| `…`, `...`, `..` | 쉼 추가, sad/plead 쪽 +1, tremor +1 (문장 중간에 여러 번이면 머뭇거림) |
| `제발`, `부탁`, `도와주세요`, `꼭`, 🙏 | plead +2 |
| `화나`, `짜증`, `왜 이래`, `아니잖아요`, 😠😡, 문장 전체 강한 반복 | angry +2 |
| `무서`, `걱정`, `떨려`, `불안` | tremor +2, plead/sad +1 |
| `감사`, `고마`, `좋아`, `행복`, `축하` | joy +1 |
| `죄송`, `미안` | plead +1 또는 sad +1 (세기 1) |
| 단서 없음 | calm |

점수가 가장 높은 감정을 선택, 동점이면 calm 쪽에 가까운 쪽(덜 극단적인 감정) 선택.

### 2단계: 대화 흐름 반영 (폰에서 즉시)
- 최근 대화 **3개**(농인 메시지 + 청인 자막 모두)의 감정을 기억한다.
- 현재 문장에 단서가 없고 앞 대화 감정이 calm이 아니면 → **앞 감정을 세기 1로 이어받음**.
  - 예) 청인: "아버님이 많이 편찮으세요" (자막 키워드 → sad) → 농인: "그렇군요 많이 힘드시겠어요" → sad, 세기 1
- 청인 자막에도 1단계 규칙의 키워드 부분을 적용한다 (이모지·ㅠㅠ 없음).

### 3단계: AI 문맥 분석 (서버, 선택 기능 — 기본 꺼짐)
- `POST /emotion/analyze` 가 작은 LLM API(예: Gemini Flash 계열)에 현재 문장 + 최근 3개 대화를 보내 감정 JSON을 받음.
- **제한 시간 0.4초.** 넘으면 1·2단계 결과 사용. 음성 출력을 절대 기다리게 하지 않는다.
- 행사판에서는 T13 검증 후 속도·비용이 괜찮을 때만 켠다 (`EMOTION_LLM_ENABLED=false` 기본).
- 보낼 때 이름 등 개인정보는 빼고 문장만 보낸다. 서버는 문장을 저장하지 않는다.

## 4. 감정 칩 (농인이 직접 고치기)
- 입력칸 위에 6개 칩 + [떨림] 칩. 자동 추정된 칩은 **옅은 테두리**로 표시.
- 칩을 누르면 그 메시지에 한해 덮어씀(`source: "chip"`) → 칩은 진한 색.
- [떨림] 칩: 누를 때마다 없음 → 약 → 중 → 강 → 없음 순환, 칩에 물결 개수(〰, 〰〰, 〰〰〰)로 표시.
- 같은 칩을 한 번 더 누르면 자동으로 돌아감.
- 보낸 뒤에는 칩이 자동 모드로 초기화.
- 칩 길게 누르기: 세기 1/2/3 선택.

## 5. 목소리에 반영하는 방법
| 요소 | 방법 |
|---|---|
| 감정 종류 | 03 문서의 제작 방식(A/B/C)에 따라: A=해당 감정 기준 음성으로 복제 / B=감정 지시문 추가 |
| 세기 | 1: 평온 기준 음성과 섞인 느낌(A: 평온 기준 사용 + 속도 조정) / 2: 기본 / 3: 지시문 강조 또는 속도·음량 조정 |
| 속도 | 감정별 기본 배율: calm 1.0, joy 1.08, sad 0.88, angry 1.0, surprise 1.12, plead 0.9 × 사용자 설정 속도. 생성 후 ffmpeg `atempo` 로 적용 |
| 쉼 | `…`, `,` 위치에 문장 분할 → 사이에 무음 삽입 (… 0.5초, , 0.2초) |
| 떨림 | 1순위: 떨림 기준 음성/지시문. 2순위(보완): ffmpeg `vibrato` 필터 — 약 f=5.5 d=0.08 / 중 f=5.5 d=0.15 / 강 f=6 d=0.25 (T13에서 들어보고 조정) |
| 음량 | angry·surprise 세기 3은 +2dB, sad는 -1dB (전체 음량 정규화 후) |

> 후처리(속도·떨림)는 GPU가 아닌 CPU에서 해도 되므로 API 서버 또는 TTS 서버 어느 쪽에서든 처리 가능. 지연이 0.1초를 넘으면 위치를 조정.

## 6. 화면에 보여주기 (농인 확인용)
- 보낸 말풍선 옆에 감정 아이콘 + 색 띠, 떨림이면 〰 표시.
- 대면 모드 위쪽(청인 쪽) 영역 테두리도 감정 색으로 → 청인도 감정을 눈으로 확인.
- 통화 받는 화면(S8)에도 감정 아이콘 표시.

## 7. 완료 확인용 테스트 문장 (T12, T13)
| 문장 | 기대 |
|---|---|
| 안녕하세요 | calm |
| 정말 감사해요!! | joy, intensity 3 |
| 괜찮아요ㅠㅠ | sad, tremor 1 |
| 괜찮아요ㅠㅠㅠㅠ | sad, tremor 2 |
| 제발 도와주세요… | plead, tremor 1 |
| 헐 진짜요?! | surprise |
| 왜 이렇게 하세요 이건 아니잖아요 | angry |
| 저… 조금… 무서워요 | plead 또는 sad, tremor 2 이상 |
| (앞 청인 자막 "많이 편찮으세요") 그렇군요 | sad, intensity 1 |
| OK 알겠어요 ㅎㅎ | joy, "오케이 알겠어요"로 읽음 |
