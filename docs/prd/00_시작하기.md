## 이 묶음은 무엇인가요?
농인이 글을 치면 감정이 담긴 목소리로 청인에게 전달되고, 청인의 말은 자막으로 농인에게 돌아오는 앱 **ITDA(잇다)** 의 제품 요구사항 문서(PRD)입니다.
안티그래비티(Google Antigravity) 에이전트가 이 문서를 읽고 **작업 단위로 하나씩** 코드를 만들도록 구성했습니다.

## 진행 방법 (매일 반복)
1. `09_작업목록_안티그래비티.md` 에서 다음 작업(T번호)을 찾습니다.
2. 해당 작업의 **"붙여 넣을 지시문"** 을 그대로 복사해 안티그래비티 에이전트 창에 붙여 넣습니다.
3. 에이전트가 끝나면 **"완료 확인"** 항목을 직접 폰으로 확인합니다.
4. 통과하면 GitHub에 저장(commit)하고 작업 목록에 ✅ 표시. 실패하면 에이전트에게 "완료 확인 ○번이 안 됩니다: (본 현상)" 이라고 알려줍니다.
5. 한 번에 한 작업만. 작업 중간에 새 기능을 추가하지 않습니다.
