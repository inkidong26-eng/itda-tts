## 5. 출시판 백로그 (행사 이후)
- 음성 70개 이상, 나만의 목소리 복제(본인 동의 필수)
- 휴대폰 본인인증 / 간편 로그인
- 일반 전화망(010) 연결 — 통신 연동 서비스 계약
- 8밴드 이퀄라이저(선택 표시)
- 국내 클라우드 GPU 이전, 상시 운영
- 다국어(대표 언어) 확장 검토, 수어 카메라 인식
- 앱스토어 앱(필요 시)
- 20~30만 명 확장 (07 문서 10절 순서대로, 1천 → 1만 → 20~30만 명 단계별): PostgreSQL 전환, 음성 파일 클라우드 저장소 + CDN, 통화 방·요청 제한 Redis, API 서버 여러 대, GPU 자동 늘리기, 24시간 캐시 개인정보 재점검, 감시·백업·장애 대응
