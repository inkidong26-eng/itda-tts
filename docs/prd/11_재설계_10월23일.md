# 11. 재설계안 (10/23 대화 정리) — 실행 전 검토용

> 상태: **제안 (아직 실행 안 함)**. 사용자 확인 후 반영한다.
> 바탕: 10/23 화면 검토 대화, 사용자 시안, "잇다 이야기". 결정 기록은 10 문서 결정 24.

## 0. 지키는 원칙 (바뀌지 않음)
1. **안정성 우선**: 겉모양을 바꿔도 대화·통화·음성 동작은 그대로. 새 기능은 꺼도 앱이 그대로 돌게.
2. **무음 금지**: 어떤 오류에서도 글은 소리로 나간다 (안 되면 폰 기본 목소리).
3. **가짜 표시 금지**: 막대·상태는 실제 신호로만. 폰 볼륨·스피커 상태처럼 알 수 없는 것은 표시하지 않는다.
4. **대화 내용은 서버에 남기지 않는다**: 통역을 켤 때만 번역 회사로 보내고, 그때는 동의를 받는다.
5. **설명은 짧게**: 화면에는 꼭 필요한 한 줄만, 자세한 설명은 화면마다 (?) 사용 설명서로.

## 1. 잇다의 철학 (설정 → "잇다 이야기")
`docs/ui/잇다_이야기.md` 글을 그대로 쓴다.

## 4. 목소리 규칙 ("평생 가져가는 목소리")
- 가입 때 한 번 고른다. 홈에는 이름만.
- **가입 후 24시간**: 자유롭게 바꿈.
- 그 뒤: **달력 기준 한 달에 한 번** (한국 시간). 바꿀 때 확인 창: "목소리는 상대가 나를 알아보는 소리예요. 바꾸면 이번 달에는 다시 바꿀 수 없어요."
- 이미 바꿨으면: "○월 1일부터 바꿀 수 있어요."
- **서버가 지킨다**: users 에 `voice_set_at`(첫 선택), `voice_changed_at`(마지막 변경) 추가. `PATCH /me` 가 규칙 위반이면 거절.
- "처음부터 다시 하기"는 새 가입 → 목소리도 새로 (설정 깊은 곳, 두 번 확인).

## 5. 외국어 통역 (행사용: DeepL 무료판)
| 항목 | 설계 |
|---|---|
| 언어 | 한국어 ↔ 영어 · 일본어 · 중국어 (시작). 국기 + 나라 이름으로 고름 |
| 농인 → 외국인 | 한국어로 씀 → 서버 `/translate` → 그 언어 목소리로 말함 (GPU 없을 땐 폰 기본 외국어 목소리) |
| 외국인 → 농인 | 폰 음성 인식을 그 언어로 → 번역 → 한국어 자막 (원문은 작게 함께) |
| 켜기 | 기본은 꺼짐. 🌐 언어를 고를 때만 켜지고 **동의 한 번**: "통역을 켜면 대화 글이 번역을 위해 DeepL(독일)로 보내져요. 무료 버전이라 보관될 수 있어요. 주민번호·계좌번호는 쓰지 마세요." |
| 고장 대비 | 번역 실패 → 원문 그대로 + 안내. 한국어 대화에는 영향 없음 |
| 서버 | 번역 키는 `.env` 에만. 번역 글은 기록하지 않음. 사용자당 분당 제한 |
| 출시판 | DeepL **유료판(Pro)**: 글 저장·학습 안 함 |
