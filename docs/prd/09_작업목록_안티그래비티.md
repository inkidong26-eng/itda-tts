- 위에서부터 **순서대로 하나씩**. 각 작업의 "붙여 넣을 지시문"을 에이전트 창에 그대로 붙여 넣는다.

- 끝나면 "완료 확인"을 **직접** 해 보고, 통과하면 GitHub에 저장(commit)한다.
- 🧑 = 사람이 직접 하는 일, 🤖 = 에이전트에게 맡기는 일.
- 막히면: "완료 확인 ○번이 안 됩니다. 화면에 ○○가 보입니다. 원인을 찾고 고쳐 주세요. 다른 기능은 건드리지 마세요."
