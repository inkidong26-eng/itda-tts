# 잇다 이야기 (설정 → "잇다 이야기" 화면에 들어갈 글, 10/23 사용자 확정)

ITDA는 이렇게 시작되었습니다.

**"소리가 없어도, 이어집니다."**

먼저 말을 걸기 어려운 불편을 덜고, 실시간으로 통화할 수 있고, 은행 창구나 관공서 같은 일상의 일도 혼자 해내기를 소원했습니다.

잇다는 그 어려운 거리를 잇는 따뜻한 다리가 되고 싶습니다.
농인이 먼저 말을 걸 수 있고, 청인과 전화로도 이야기할 수 있고, 혼자서도 일상의 일을 해낼 수 있도록.

우리 사회에 어려움이 있다면 살피고, 차별 없는 밝은 미래를 함께 만들어 가기 위함입니다.
